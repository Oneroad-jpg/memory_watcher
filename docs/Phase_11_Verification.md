# 工程11 軽量性・非通信検証記録

## 実装範囲

- アプリ自身の累積CPU時間と常駐メモリを時刻付きで観測する
- 対象プロセスのInternet socketを観測する
- 製品ソースの通信APIと通知APIを静的検査する
- SQLiteの整合性、実容量、保持上限での予測容量を検査する
- 24時間、4回以上の固定観測から `PENDING`・`PASS`・`HOLD`を機械判定する
- 履歴表示と保持期間を12時間・24時間・3日に変更する

監査のチェックポイントと実機観測値は製品DBおよび公開リポジトリから分離し、
公開記録には工程の判定に必要な集約値だけを保存します。

## 履歴保持と表示期間

owner指示により、従来の24時間・7日・30日表示を12時間・24時間・3日へ
変更しました。

- 5秒の生データは24時間保持する
- 1分集約データは3日保持する
- 既存SQLiteとの互換用5分集約データは3日保持する
- 集約成功後にだけ対象の生データを整理する
- 12時間と24時間は生データ、3日は1分集約を表示する
- スリープおよび欠落区間は補間せず空白表示する

保持境界、容量上限の直前と直後、履歴期間の選択、表示点数、空白区間を
単体テストで確認しました。

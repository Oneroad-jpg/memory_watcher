# Phase 00 Verification — Requirements

## 判定

工程0「要件固定」は、次の全項目を満たした場合に完了とします。

- [x] v0.1の目的が文書化されている
- [x] 対象機能が文書化されている
- [x] 対象外機能が文書化されている
- [x] 5秒測定が固定されている
- [x] 24時間・7日・30日の表示期間が固定されている
- [x] スリープ区間を空白にする要件が固定されている
- [x] 保存先がローカルSQLiteだけに固定されている
- [x] Activity Monitorと同傾向であり、完全一致を保証しないと明記されている
- [x] メモリプレッシャーの不明状態を推測しない
- [x] 通知、外向き通信、クラウド保存、プロセス別解析を対象外にしている
- [x] 対応OS、CPU、UI技術、保存方式、配布形態が固定されている
- [x] 公開できる成果物と非公開の開発情報が区別されている
- [x] READMEにCodexによるノンコード開発であることが明記されている
- [x] 未決定項目がない

## 公開境界検査

公開対象は製品のソース、テスト、リソース、一般向け文書、
一般的なビルド補助スクリプトに限定します。端末固有情報、資格情報、
認可情報、受領記録、非公開ログ、製品に不要な内部操作情報を含めません。

この検査は工程0だけで終了せず、以後の全工程でコミット、PR、マージ前に
繰り返します。

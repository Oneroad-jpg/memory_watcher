# Dashboard Layout Contract v1

## 目的

Memory Watcherの広いウインドウで生じる余白を減らし、利用者が見たい情報量を
アプリ内で調整できるようにするための表示契約です。本書でいう「CMS」は、
サーバー上のコンテンツ管理ではなく、ローカルの表示構成エディタを意味します。

## 変更できるもの

- 表示密度プリセット: `compact`・`balanced`・`detailed`
- メモリ履歴、Mac全体CPU、論理CPU別履歴、選択時刻詳細の表示順
- 論理CPU別履歴と選択時刻詳細の表示・非表示
- 設定を既定の`balanced`へ戻す操作

プリセットは余白、セクション間隔、現在値領域、グラフ高さ、論理CPUカード幅を
一括して決めます。個々の数値を無制限に入力させず、読みやすさと性能を保てる
検証済み範囲だけを提供します。

## 変更できないもの

- 5秒の測定周期、メモリ・CPUの取得元と計算式
- SQLite schema、履歴の保持期間、12時間・24時間・3日の保存層
- sleep、UNKNOWN、取得不能、再起動、gapの意味と空白表示
- メモリ履歴、Mac全体CPU、期間選択、監視状態の完全な非表示
- 通知、外向き通信、クラウド同期、アカウント、分析送信
- GPU、アプリ別・プロセス別解析、AI

## 既定値

初回起動、保存設定なし、decode失敗、未知のschema versionでは`balanced`を使い、
すべてのセクションを標準順で表示します。既定値は現行v0.2の情報量を失いません。

| 項目 | compact | balanced | detailed |
|---|---:|---:|---:|
| 現在値領域の高さ比 | 0.34 | 0.42 | 0.48 |
| 外側余白 | 12 | 18 | 24 |
| セクション間隔 | 8 | 10 | 12 |
| メモリグラフ高さ | 185 | 215 | 250 |
| スワップグラフ高さ | 62 | 74 | 88 |
| Mac全体CPUグラフ高さ | 130 | 155 | 185 |
| 論理CPUグラフ高さ | 58 | 70 | 82 |

## 保存と回復

- schema versionを持つ`Codable`設定だけをローカルUserDefaultsへ保存する
- 保存keyは`dashboard.layout.configuration.v1`
- セクション重複は最初の1件だけを採用する
- 欠けた既知セクションは標準順の末尾へ補う
- 非表示不可のセクション指定は無視する
- 未知schema、decode不能、範囲外値は推測せず既定値へ戻す
- SQLiteの測定履歴とレイアウト設定を混在させない

## アクセシビリティと性能

- キーボードだけでプリセット、順序、表示状態、resetを操作できる
- VoiceOverで各設定名と現在値を読み取れる
- 設定変更で監視エンジンや履歴DB接続を作り直さない
- ウインドウ非表示中にレイアウト変更起因の履歴再読込を行わない
- 最終工程で表示・非表示それぞれのCPU平均1%未満を再確認する

## 非保証境界

任意の座標へ部品を自由配置するデザインツール、テーマ作成、プラグイン、
設定共有、クラウド配信はv0.3の対象外です。Intel Macではbuildを確認し、
実機で未検証の表示条件は未検証と明記します。

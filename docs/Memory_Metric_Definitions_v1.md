# Memory Watcher メモリ指標定義 v1

## 目的

Memory Watcherが表示・保存する値の取得元、計算式、確実性を固定します。
Activity Monitorと同じ概念を参照しますが、非公開の内部計算との完全一致は
保証しません。導出値は画面上でも推定または相当量と明記します。

AppleはActivity Monitorのメモリ画面について、物理メモリ、使用量、
アプリメモリ、有線メモリ、圧縮、キャッシュファイル、スワップ使用量を
区別しています。

- [Activity Monitorでメモリ使用状況を確認する](https://support.apple.com/guide/activity-monitor/view-memory-usage-actmntr1004/mac)
- [`vm_statistics64_data_t`](https://developer.apple.com/documentation/kernel/vm_statistics64_data_t)

## 入力値

| 記号 | 取得元 | 意味 |
|---|---|---|
| `P` | `host_page_size` | 1ページのバイト数 |
| `R` | `ProcessInfo.physicalMemory` | 物理メモリ総量 |
| `F` | `free_count` | 空きページ数（投機ページを内包） |
| `I` | `internal_page_count` | 内部ページ数 |
| `Q` | `purgeable_count` | パージ可能ページ数 |
| `W` | `wire_count` | 有線ページ数 |
| `C` | `compressor_page_count` | コンプレッサー内ページ数 |
| `E` | `external_page_count` | 外部ページ数 |
| `S` | `vm.swapusage.xsu_used` | 使用中スワップのバイト数 |

ページカウンターは `host_statistics64(HOST_VM_INFO64)` から取得します。
すべての計算は符号なし整数の桁あふれと物理メモリ超過を検査します。

## 計算式 `phase-03-v2`

| 画面名 | 計算式 | 分類 |
|---|---|---|
| 物理メモリ | `R` | OS報告値 |
| 使用量（推定） | `R - (F × P) - ((E + Q) × P)` | 導出推定値 |
| アプリ相当（推定内訳） | `(I - Q) × P` | 導出推定値 |
| 有線メモリ | `W × P` | OSカウンター換算値 |
| 圧縮メモリ | `C × P` | OSカウンター換算値 |
| キャッシュ相当 | `(E + Q) × P` | 導出推定値 |
| その他使用相当 | `使用量（推定） - アプリ相当 - 有線 - 圧縮` | 導出推定値 |
| スワップ使用量 | `S` | OS報告値 |

`使用量（推定） = アプリ相当（推定内訳） + 有線メモリ + 圧縮メモリ
+ その他使用相当` として常に再計算可能にします。使用量（推定）と
キャッシュ相当と空きメモリの合計は物理メモリと一致します。主要3構成が
使用量（推定）を超えるサンプルは拒否します。

## 比較時の注意

- Activity Monitorの完全な内部計算式は公開APIとして保証されていないため、
  使用量とキャッシュを完全一致とは表示しません。
- `top` の `PhysMem used` はActivity Monitorの `Memory Used` と同一名称・
  同一意味として扱いません。
- `top` の `wired` と `compressor` は、有線メモリと圧縮メモリの独立した
  同時観測として使用します。表示はMiB単位に丸められ、更新時刻も完全には
  同期しないため、近接時刻の範囲と変化方向を比較します。
- 連続的なメモリプレッシャー曲線は本計算式から生成しません。

## 取得品質とgap

ページカウンターはカーネル内で変化し続けるため、同じ構造体に返された値でも
収支が一時的に整合しない場合があります。Memory Watcherは次の品質情報を
保持します。

| 品質 | 意味 |
|---|---|
| `firstPass` | 初回取得値が全検査を通過した |
| `retried` | 不整合後の有界再取得値が全検査を通過した |
| gap | 最大3回の取得がすべて不整合で、測定値を生成しなかった |

再取得は不整合時だけ50ミリ秒間隔で最大2回行います。gapにはUTC時刻、
システム稼働時間、試行回数、最後の生カウンター、理由、超過量を保持します。
gapを0、前回値、上限へ丸めた値で埋めません。

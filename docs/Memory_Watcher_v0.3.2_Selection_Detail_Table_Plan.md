# Memory Watcher v0.3.2 選択時刻詳細表 工程表

## 目的と範囲

工程23では、履歴末尾の「選択UTC」と小さな数値カードを、文字の大きい表形式へ
変更します。正確な選択時刻、Pressure、メモリ、測定区間、Mac全体CPU、
user・system・nice・idle、全論理CPUの値は保持します。

メモリ・CPUの測定式、5秒間隔、SQLite schema、保持期間、sleep・UNKNOWN・gap、
通信・通知境界、グラフと表示設定は変更しません。「選択時刻の詳細」を表示設定で
非表示にできる既存動作も維持します。

## 工程23

| 実装内容・成果物 | 完了条件 |
|---|---|
| 選択時刻の見出しを明確化 | 表示名を「選択時刻（UTC）」とし、見出しはheadline、日時はtitle3相当の等幅数字で表示する。Pressureを同じ行の読みやすいバッジにする。 |
| 保存値を表形式へ変更 | 「項目・値・測定区間」の列を持ち、メモリとMac全体CPUを整列表示する。未測定は推測せず「この時刻は未測定」と表示する。 |
| CPU詳細を表形式へ変更 | user・system・nice・idleを2列表、論理CPUを「CPU・使用率」の2組4列表として表示する。奇数CPUでも欠落や範囲外参照を起こさない。 |
| 読みやすさと幅の検証 | 数値本文はbody相当以上とし、標準1,080 pointsと最小780 pointsで文字の重なり・切断がない。8論理CPUの全値へ一画面またはスクロールで到達できる。 |
| 機能回帰 | 12時間・24時間・3日で時刻選択が機能し、メモリ、CPU全体、CPU内訳、全論理CPU、Pressure、測定区間を保持する。sleep・UNKNOWN・gapを補間しない。 |
| 公開・導入 | 全テスト、Release build、Intel build、strict format lint、SQLite整合性、非通信・非通知・公開境界scanがPASSする。工程23を1個の非merge commit、ready PR、merge commit、remote readbackで完了し、v0.3.2をインストールして実画面と記録継続を確認する。 |

## 停止規則

- 固有情報の欠落、表の重なり、時刻選択の退行、CPU系列欠落、テスト失敗、
  SQLite不整合、通信・通知API、公開情報漏洩を検出した場合は工程23で停止します。
- 表を整えるために保存値を平均化、推測、補間しません。
- 既存の実測履歴と表示設定を移行・削除しません。
